# Ekara

Проект представляет собой интеграцию Laravel с Doctrine ORM и Sanctum. Ядро фреймворка осталось практически нетронутым — переписаны только инфраструктурные трейты Eloquent, а поверх ядра добавлены собственные модули (_в каталоге packages_).

Из наиболее интересных решений стоит выделить шины (`EventBus`, `CommandBus`, `QueryBus`, `NotificationBus`, `ProcessBus`) и тип `Result` — аналог одноимённого типа из Rust, адаптированный под PHP. Также был выполнен прогрев JIT-компилятора и в планах — адаптация под highload (RoadRunner/Swoole).

Проект задуман для разгрузки shared kernel и выноса ключевых компонентов в foundation. Это позволит просто установить пакет и разрабатывать DDD-проекты с гексагональной архитектурой на Laravel. В некоторых местах я намеренно отступил от канонов, поскольку строгое следование правилам Эванса на Laravel делает реализацию проектов неосуществимой — иначе разработка превращается в борьбу с PHP и ядром фреймворка.

В целом получается достаточно сильная архитектура: она масштабируема, содержит логику (_в отличие от слоистой_) и требует высокой дисциплины от разработчика. Это уже не игрушки и не для баловства, как обычная слоистая архитектура и Eloquent. Это нечто более серьёзное — для коммерческих проектов, где важны стабильность, предсказуемость и масштабируемость.
